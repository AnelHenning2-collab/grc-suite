## What It Does

Logical Coders GRC Suite gives a cybersecurity consultant a complete, client-facing workflow platform to deliver a structured **90-Day Security Governance Pilot** — from client intake through final audit-ready deliverables. No enterprise software license. No manual document assembly. One platform, one engagement, one click to generate every report.

---

## Features

| Module | What It Does |
|--------|-------------|
| **Client Intake** | Captures organization, framework, scope, and pricing — auto-fills the entire engagement |
| **Risk Mapper** | Asset inventory, threat mapping, likelihood × impact scoring, visual risk matrix |
| **Evidence Builder** | Control-by-control evidence planning across HIPAA, NIST CSF 2.0, ISO 27001, SOC 2, FedRAMP |
| **90-Day Playbook** | 18 structured tasks across 3 phases with live progress tracking |
| **Report Generator** | One-click Engagement Proposal, Risk Analysis, Gap Analysis, and Outcomes Report |
| **Session Persistence** | All data saves automatically — pick up any engagement where you left off |

---

## The 90-Day Engagement Model

```
Phase 1 · Days 1–30          Phase 2 · Days 31–60         Phase 3 · Days 61–90
─────────────────────        ──────────────────────        ──────────────────────
✓ Asset inventory            ✓ HIPAA-compliant email       ✓ Staff security training
✓ Security Risk Analysis     ✓ 3 core security policies    ✓ Evidence collection
✓ Business Associate Agmts   ✓ Evidence planning           ✓ Gap analysis validation
✓ Risk map to leadership     ✓ Gap analysis update         ✓ Final Outcomes Report
```

## Supported Frameworks

- **HIPAA Security Rule** — §164.308–§164.312, OCR audit protocol
- **NIST CSF 2.0** — Govern, Identify, Protect, Detect, Respond, Recover
- **ISO 27001:2022** — Annex A controls
- **SOC 2 Type II** — Trust Service Criteria
- **FedRAMP** — Moderate baseline controls

> 93% of OCR-investigated HIPAA breaches in 2024 cited a missing or inadequate Security Risk Analysis.
