1. Executive Summary

This Security Risk Analysis was conducted for Meridian Health Systems in accordance with HIPAA §164.308(a)(1)(ii)(A) and NIST CSF 2.0 Identify (ID.RA) function. Meridian maintains an existing Information Security Management System (ISMS); this assessment identifies current residual risks following implementation of controls established in the prior fiscal year.

The assessment identified 8 risk items across enterprise systems and operational processes. Two Critical findings — medical IoT device vulnerabilities and legacy PACS infrastructure — require immediate escalation to the Security Steering Committee and executive leadership.

3. Findings

Critical (2): Medical IoT devices and legacy PACS infrastructure represent the highest organizational risk. The combination of unpatched firmware across 340+ IoT devices with no network segmentation creates a viable attack path to the Epic EHR. The 2024 Change Healthcare ransomware attack — which impacted similar IoT-connected hospital networks — demonstrates the real-world consequences of this exposure pattern. Both findings require immediate Security Steering Committee escalation.

High (5): The M365 environment, Active Directory privileged access posture, Epic supply chain risk, third-party billing vendor, and Azure misconfiguration findings each present meaningful risk to ePHI confidentiality and availability. The vendor risk finding is particularly time-sensitive: the current billing vendor BAA does not reflect updated HIPAA Omnibus Rule requirements, creating regulatory exposure independent of technical risk.

Medium (1): BYOD enforcement is in progress. Legal review of the MDM policy should be expedited to close this gap within the current quarter.

4. Recommendations

  1. Immediate — IoT: Implement network segmentation (VLAN isolation) for all medical IoT devices within 30 days. Establish a dedicated IoT asset inventory and patch management cycle.
  2. Immediate — PACS: Document compensating controls for all Windows 7 legacy nodes. Engage vendor for migration roadmap. Air-gap critical nodes pending upgrade.
  3. 30 days — Identity: Accelerate PAM solution procurement and deployment. Reduce privileged account standing access; implement just-in-time (JIT) access for all domain admin roles.
  4. 30 days — Email: Complete DMARC enforcement and extend MFA policy to all accounts including executive level. Conduct targeted BEC phishing simulation for finance and HR teams.
  5. 45 days — Vendor: Re-assess billing vendor using updated questionnaire. Obtain current SOC 2 Type II report. Update BAA to reflect Omnibus Rule requirements.
  6. 60 days — Cloud: Resolve all CSPM findings. Implement automated misconfiguration alerting and enforce DLP policies across all Azure storage with ePHI classification tags.
  7. 90 days — BYOD: Enforce MDM policy. Deploy mobile application management (MAM) containerization for ePHI access on personal devices.
  8. Ongoing: Integrate threat intelligence feeds with SIEM. Schedule quarterly risk reassessment for all Critical and High findings. Retain this analysis per HIPAA §164.530(j).
