1. Executive Summary

Thank you for the opportunity to partner with Meridian Health Systems. Meridian maintains an established security program and dedicated CISO function — this engagement is designed to complement your existing capabilities, not replace them. Logical Coders brings external governance expertise, structured evidence methodology, and NIST CSF 2.0 alignment to accelerate closure of the residual gaps identified in your most recent risk assessment.

The risk assessment identified 8 risks including 2 Critical findings (medical IoT and legacy PACS infrastructure) and 1 active evidence gap in continuous monitoring (DE.CM-01). These findings create measurable regulatory and operational exposure that this engagement will directly address.

Logical Coders proposes a 90-Day Enterprise Security Governance Pilot focused on IoT risk remediation, SIEM coverage expansion, PAM acceleration, and evidence package completion for NIST CSF 2.0 and HIPAA dual-framework reporting.

2. Proposed Scope — 90-Day Enterprise Pilot

Phase 1  ·  Days 1–30  ·  IoT & Inventory
Close the Highest-Risk Gaps
  • Complete medical IoT device inventory — all 340+ units including firmware versions and network location
  • Design and implement VLAN segmentation plan for IoT devices (coordinate with network team)
  • Initiate IoT onboarding to Splunk SIEM — establish baseline monitoring for all IoT network segments
  • Update HIPAA Security Risk Analysis with Phase 1 findings; present to Security Steering Committee
  • Re-assess third-party billing vendor; obtain current SOC 2 Type II; update BAA to Omnibus standards
Phase 2  ·  Days 31–60  ·  Identity & Monitoring
Strengthen Detection & Access Controls
  • Complete Splunk alert tuning — reduce false positives; define and document SOC alert response SLAs
  • Enforce MFA on all remaining accounts including executive exceptions; document and remediate all exceptions
  • Support CyberArk PAM deployment milestone — just-in-time access for all domain admin roles
  • Complete CSPM finding remediation in Azure; enforce DLP policies across all ePHI-classified storage
  • Deliver Phase 2 status report to CISO and Security Steering Committee
Phase 3  ·  Days 61–90  ·  Evidence & Validate
Evidence Package & Dual-Framework Reporting
  • Collect and organize evidence for all 5 NIST CSF 2.0 priority controls
  • Cross-map NIST CSF evidence to HIPAA Security Rule requirements (dual-framework evidence package)
  • Validate evidence quality for board-level NIST CSF Govern reporting (GV.OC-01)
  • Deliver DMARC enforcement completion for M365; validate BEC protections
  • Deliver final 90-Day Outcomes Report with full dual-framework evidence package
  • Recommend next wave: SOC maturity, third-party risk program expansion, HICP implementation
