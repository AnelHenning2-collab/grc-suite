Section 05
Remediation Roadmap — 12-Month Plan to CMMC Level 2
1
Phase 1 · Months 1–3 · Critical Foundation
  • Enable MFA on all systems accessing CUI (IA.3.083)
  • Implement RBAC — remove shared accounts and standing admin access (AC.1.001)
  • Deploy centralized audit logging on all CUI-touching systems (AU.2.041–042)
  • Enable FIPS 140-2 mode on all endpoints and servers (SC.3.177)
  • Conduct initial security awareness training for all 47 staff (AT.2.056)
2
Phase 2 · Months 4–6 · Policy & Configuration
  • Document hardened baseline configurations for all system types (CM.2.061)
  • Write Incident Response Plan — with CUI breach notification procedures (IR family)
  • Draft System Security Plan (SSP) — document all 110 controls (CA.2.157)
  • Implement key management policy and tooling (SC.3.187)
  • Deploy EDR solution on all workstations and servers (SI.2.214)
3
Phase 3 · Months 7–9 · Evidence & POA&M
  • Complete Plan of Action & Milestones (POA&M) for all remaining gaps
  • Conduct vulnerability scans on all in-scope systems (RA.2.141–142)
  • Implement patch management program with defined SLAs (SI family)
  • Complete media protection controls — marking, transport, sanitization (MP family)
  • Collect and organize evidence for all 110 controls in audit binder
4
Phase 4 · Months 10–12 · Pre-Assessment Readiness
  • Conduct internal mock CMMC assessment against all 110 controls
  • Remediate any remaining gaps identified in mock assessment
  • Deliver tabletop incident response exercise (IR.2.092–093)
  • Final review of SSP, POA&M, and evidence binder
  • Engage C3PAO (Certified Third-Party Assessment Organization) for official assessment
